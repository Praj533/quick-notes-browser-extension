# Quick Notes Browser Extension

A beginner-friendly Google Chrome extension that saves a short note in local browser storage.

## Features
- Save a short note.
- Retrieve the note when the popup is opened again.
- Clear the saved note.
- No account or external server is required.

## Installation for testing
1. Download or clone this repository.
2. Open Chrome and visit `chrome://extensions`.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the project folder.
5. Click the Quick Notes extension icon to use it.

## Technologies
HTML, CSS, JavaScript, Chrome Extensions Manifest V3 and `chrome.storage.local`.

## Privacy
The note is stored locally in the browser using Chrome extension storage. Do not save passwords or other sensitive information in this demonstration extension.
